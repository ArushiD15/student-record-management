Program 1: Student Record Management System
Problem Statement:
Develop a menu-driven program to manage student records.
Each student record should contain:
- Roll number
- Name
- Marks in three subjects
- Total marks
- Average marks
- 
The program should allow the user to:
1. Add a new student record.
2. Display all student records.
3. Search for a student using the roll number.
4. Update a student’s marks.
5. Delete a student record.
6. Sort students according to total marks.
7. Display the student with the highest marks.
8. Exit the program.

Requirements
- Use a "structure" to store student details.
- Store multiple student records using an array of structures.
- Use separate functions for adding, displaying, searching, updating, deleting, and sorting records.
- Pass arrays and structures to functions.
- Use pointers wherever appropriate.
- Handle invalid menu choices and duplicate roll numbers.
- The program should support at least 50 students.

C Concepts Revised

- Structures
- Arrays
- Functions
- Pointers
- Searching
- Sorting
- Loops and conditional statements
- Menu-driven programming
- String handling
